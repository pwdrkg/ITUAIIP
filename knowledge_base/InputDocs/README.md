# Source documents

Committed here: Philippine government works only (laws, NCIP, NPC, DepEd, DTI/DOST issuances and Supreme Court decisions), which are not covered by copyright (IP Code s176). Scanned documents are committed as OCR text (`*_ocr.txt`, made with Tesseract on 9 November 2026); proofread before quoting.

Everything else (UN, foreign and academic documents, news and NGO reports) is not committed. Download it with `python scripts/fetch_sources.py`, or save it by hand as `<folder>/<id>_<name>` using the links in `../sources.csv`.
