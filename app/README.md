# Web interface

Planned screens:

1. **Consent**: explained in the teller's language; record or withdraw consent.
2. **Record**: one teller per session, works offline; teller names their own group.
3. **Upload documents**: photos or scans of maps, genealogies, written accounts.
4. **Review**: community translators check transcripts and translations.
5. **Read-back**: the consensus story with agreement scores, played or read to the community.
6. **Simulation dashboard**: scenario events, agent assessments and the audit log.
